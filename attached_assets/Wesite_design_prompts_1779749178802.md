# Wesite design prompts   
  
Create a football live score and streaming website with a UI style very similar to MatchFoari.com.  
  
Design requirements:  
- Full dark theme  
- Compact mobile-first layout  
- Black and dark gray background  
- Green live badges  
- Match cards similar to MatchFoari  
- Horizontal scrolling live matches  
- Rounded cards  
- Simple top navigation  
- Football-focused modern interface  
- Match cards with:  
  - team logos  
  - score  
  - live status  
  - watch button  
  - match time  
- Sticky bottom mobile navigation  
- Large live match banner  
- Stream page with embedded player  
- Match details below stream  
- Minimal clean spacing  
- Sports streaming app style  
- Fast lightweight design  
- Use Tailwind CSS  
- React frontend  
- Responsive for iPhone screens  
- Similar spacing, sizing, and card structure to MatchFoari  
  
Pages:  
- Home  
- Live Matches  
- Match Details  
- Streaming Page  
- Highlights  
- Admin Dashboard  
  
Animations:  
- Smooth hover effects  
- Live pulse animation  
- Sliding cards  
- Smooth transitions  
  
Make it feel like a real football streaming platform similar to MatchFoari while keeping original branding and original code structure.
